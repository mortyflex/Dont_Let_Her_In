# Visual References — Don’t Let Her In

These images are visual references for the horror direction of the prototype.

They are not final game assets.

They must be used only to guide:

- composition
- lighting mood
- color palette
- corridor readability
- elevator framing
- creature silhouette
- UI atmosphere later

Do not use these images as in-game textures.

Do not import them as materials.

Do not build final art from them directly.

The current goal is to improve the placeholder scene while keeping it simple and performant.
